# This repo contains examples of the code for Common Data Structures and Algorithms (DSA)

Each topic is implemented twice, in parallel, so the same concepts can be compared across languages:

- [JavaScript](./javascript)
- [Python](./python)

Both trees cover the same topics: arrays, hash tables, linked lists, binary search trees, sorting, dynamic programming, recursion, and a handful of practice problems.

See also: [What is a data structure?](./what_is_a_data_structure.md)
